# Multi-Utility Calculator in Python

## Overview

This project is a **Multi-Utility Calculator** developed using **Python**. It performs various mathematical and scientific calculations through a menu-driven approach.

The project includes basic arithmetic operations along with additional utilities such as factorial calculation, power calculation, temperature conversion, number system conversion, equation solving, trigonometric calculations, unit conversions, area and perimeter calculations, and volume calculations.

## Features

### Basic Calculator

* Addition
* Subtraction
* Division
* Multiplication

### Mathematical Calculations

* Factorial Calculator
* Power Calculator
* Percentage Calculator
* Quadratic Equation Solver
* Linear Equation Solver

### Temperature Conversion

* Fahrenheit to Celsius
* Celsius to Fahrenheit

### Number System Conversion

* Decimal to Binary
* Decimal to Octal
* Decimal to Hexadecimal

### Trigonometry

* Sine
* Cosine
* Tangent
* Inverse Trigonometric Functions
* Degree to Radian Conversion
* Radian to Degree Conversion

### Unit Conversions

* Meter to Feet
* Feet to Meter
* Kilogram to Pound
* Pound to Kilogram
* Seconds to Minutes
* Meter per Second to Kilometer per Hour
* Pascal to Atmosphere
* Watt to Horsepower

### Geometry and Measurement

#### Area and Perimeter

* Circle Area and Perimeter
* Rectangle Area and Perimeter
* Triangle Area

#### Volume Calculator

* Cube Volume
* Sphere Volume
* Cylinder Volume
